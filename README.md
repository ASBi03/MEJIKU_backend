# MEJIKU - Auth System (Backend & Frontend)

Project ini dilakukan untuk pengembangan website MEJIKU pada sistem autentikasi pengguna (Registrasi, Login, dan Reset Password). Sistem ini dibuat untuk memenuhi target OKR dalam membangun fungsi katalog dan portal komunitas.

## Fitur Utama
* **Registrasi Pengguna:** Mendaftarkan akun baru dengan validasi data.
* **Login Pengguna:** Autentikasi aman untuk akses dashboard/katalog.
* **Lupa Password (OTP):** Sistem pemulihan akun menggunakan kode keamanan unik.
* **Database Integration:** Penyimpanan data pengguna yang aman melalui Supabase Auth.

## Teknologi yang Digunakan
* **Backend:** Node.js, Express.js
* **Keamanan:** Crypto (untuk OTP), Supabase Auth SDK
* **Database:** Supabase (PostgreSQL)
* **Frontend:** Nest.js
